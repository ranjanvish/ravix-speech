# Local bridge and ordered voiceover runner (experimental)

The bridge binds only to 127.0.0.1:17842 and requires a random token. Start it with `python bridge/server.py`; its token and SQLite queue are stored outside the extension folder in `R:\Google-AI Studio\speech-bridge-data`. Pair by pasting the token into the extension panel. Reload the extension and refresh the AI Studio tab after installing this release. A single matching AI Studio speech tab is required. The extension uses a browser alarm to poll the bridge; processing can take roughly 30 seconds per command. An already dispatched command is not automatically repeated after interruption. Inspect job status before deciding how to recover.

The bridge accepts `scan`, `fill`, `prepare_turn`, `run_turn` and `download`. These commands are experimental and use semantic labels from observed UI; site changes, localization, background throttling, inaccessible audio source, or a nonmatching download can cause them to stop. There is no 99% reliability claim or unattended recovery guarantee. A run is blocked if an existing player cannot be tied to a previously verified download. No code reads login cookies or API keys. A completed browser download is checked for its source, state, filename and nonzero size; the runner additionally checks WAV headers, frames and copied file size.

For an agent, `python bridge/run_project.py bridge/rama-ravana-project.json --output "R:\Google-AI Studio\rama-ravana-output"` queues the six turns sequentially. The project supports 1–100 turns, each with speaker, voice, style and text; it generates one turn per request so more than two characters can be handled without assuming more than two speakers per generation. It writes separate WAVs and a JSON manifest. It refuses to overwrite an existing output manifest and stops on ambiguous state, failure, invalid WAV or missing backup. It does not automatically concatenate, listen to, approve, or guarantee a 30-second result. Select Gemini 3.8 Flash TTS and open a fresh single-block dialog in AI Studio before using it. Voice availability and correct performance must be independently auditioned.

Agent API: send authenticated POST `/enqueue` with `{ "action": "scan|fill|prepare_turn|run_turn|download", "payload": {...} }`; poll GET `/status`. Never expose the token, permit remote access, or assume a dispatched command succeeded after a timeout. The local HTTP queue was integration-tested; the actual installed extension, AI Studio DOM actions, background operation and downloads have NOT yet been tested end-to-end for this release. Do not claim audio output until real files are verified and reviewed.
