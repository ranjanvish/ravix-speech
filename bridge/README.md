# RAVIX Speech local bridge

The bridge is `server.py` in this folder and binds to `127.0.0.1:17842`. By default its SQLite queue and token live in `RAVIX Speech/speech-bridge-data` under the main RAVIX installation; `SPEECH_BRIDGE_DATA` can override this. The browser extension must be loaded in the intended browser profile. A recent heartbeat and a fresh scan are required to confirm connectivity. Do not copy, disclose or remove the queue or token during migration.

The current implementation permits unauthenticated loopback access and broad CORS; it is not a strict token-enforced security boundary. Keep it on a trusted computer. The older `run_project.py` expects `prepare_turn` and `run_turn` actions that the current content handler does not implement; it is not a verified end-to-end runner. Use the current RAVIX Speech commands and `docs/INSTANT-RUNBOOK.md` instead. Check each job before retrying; preserve existing audio and verify a downloaded WAV. Browser profile state and external scripts may still reference an old path, so inspect them before deleting a junction.
