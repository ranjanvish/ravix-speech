# राम–रावण production checklist

1. Speech only: six spoken turns in original order; visuals, explosions, music and shankh are not spoken by the TTS model. “जय श्री राम” is a separate crowd/voiceover cue if requested, not silently added to either character.
2. Cast masculine voices intentionally: Ravana Algenib and Rama Achird are starting candidates, not verified performance. Listen to Hindi samples and adjust. Do not use the language filter by default.
3. Style per turn: threatening Ravana; Rama controlled anger; Ravana proud defiance; Rama steadfast conviction; Ravana desperate cry; Rama dignified triumph. Exact text is preserved. No arbitrary breaths or tags; try an expression only at a justified instant.
4. Generate and listen; check speaker identity, pronunciation, emotional tone and delivery. Save and verify each output before a rerun. Review 30-second total timing with space for the six scene windows, music, explosions and final chant; model timing is not guaranteed and may need editing.
5. This extension currently creates a plan and can fill only the first block. It cannot auto-cast, populate a dialogue, run, download, or provide an agent bridge. Page Eye is an on-demand DOM snapshot, not screenshot vision. Do not claim a generated audio file without verifying it.
