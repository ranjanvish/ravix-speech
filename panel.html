Script और direction

एक narrator के लिए एक block; dialogue में हर turn को क्रम से तैयार करें।

यह बटन केवल पहले speech block का text बदलता है। Style और voice AI Studio में चुनें। बदलाव के बाद पेज पर जाँचें।

Local agent bridge

Local bridge को पहले शुरू करें, फिर उसकी pairing token file का token यहाँ डालें।

Bridge में experimental single-turn voice, style, Run और download actions हैं। Live AI Studio पर सत्यापन अभी आवश्यक है; पहचान अस्पष्ट होने पर यह रुकता है।

Dialogue project

पात्र और उनके क्रमवार संवाद JSON में रखें। पात्र और voice की presentation जाँचें; अलग पात्रों को अलग आवाज़ दें। क्रमवार batch में अधिकतम दो पात्र रखे जाते हैं।

अभी plan नहीं बना है।

यह planner क्रम, casting और वास्तविक batches दिखाता है; audition और presentation की कमी को स्पष्ट करता है। वर्तमान version AI Studio में सभी blocks, voice या style अपने आप नहीं भरता और Run या download नहीं करता।

Backup और generation

  1. पिछला परिणाम Download करें और फ़ाइल सुरक्षित होने की पुष्टि करें।
  2. Speaker, style, block order और script जाँचें।
  3. AI Studio में Run करें; नया परिणाम फिर डाउनलोड करें।
नया Run पुराने player को बदल सकता है। यह extension download स्वतः सत्यापित या Run को रोकता नहीं है।

Performance quick guide

  • पहले दृश्य, पात्र की मंशा और तनाव समझें; फिर style लिखें।
  • Gender filter उपयोग करें; Language filter खाली रखें।
  • Expression केवल ज़रूरत के पल पर; बिना कारण breath या pause न जोड़ें।
  • पात्र की gender presentation और voice presentation जाँचें; नाम से voice का gender न मानें। अलग पात्रों के लिए अलग voice audition करें।
  • हर संवाद अलग सुरक्षित करें जहाँ संभव हो; एक फाइल में जोड़ने से पहले सीमाएँ सुनकर जाँचें। Forced alignment अकेला प्रमाण नहीं है।
  • कई characters के लिए दो-speaker सीमा जाँचें और क्रमवार हिस्सों में output जोड़ें।
  • Temperature default पर रखें; बेहतर sound के लिए audition ज़रूरी है।
